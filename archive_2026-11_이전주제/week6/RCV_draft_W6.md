## 한눈에 보기
- **무엇을 했나**: 이민혁(MuJoCo)이 만든 4단계 현실 특성 실험 4가지(4-1 관절 건마찰, 4-2 기어 백래시, 4-3 3상 PWM 인버터, 4-4 권선 열 모델)를 MATLAB(Simulink/Simscape)에서 같은 가정 조건으로 다시 구현하고 결과를 비교했다. 기준 모델은 5주차 3-2(기어비 5, 관절 환산 회전자 관성 0.0025)이고, 그 모델을 복사해 필요한 곳만 바꿨다.
- **결과**: 두 환경이 같은 식을 푸는 실험(4-3 PWM 43/43, 4-4 열 67/67)은 검사를 모두 통과했다. 정의가 다른 실험(4-1 마찰 56/69, 4-2 백래시 56/109)은 일부 실패했고, 이는 마찰·접촉 모델 자체가 달라 구현 오류와 모델 차이를 구분할 수 없는 부분이다.
- **알게 된 것**: MuJoCo와 Simscape는 마찰(제약 vs 속도 함수)과 접촉(solref/solimp vs 강성·감쇠)을 다르게 모델링해, 선택한 기본 마찰·접촉 모델로는 같은 파라미터 값만으로 동등한 조건이 되지 않는다(공통 힘 계산식을 양쪽에 구현하면 추가 비교는 가능하나 이번에는 하지 않았다). 같게 맞춘 것은 마찰 크기 0.05 N·m와 유격 폭 ±0.5도뿐이다.
- **한계**: 모든 값은 가정값이며 하드웨어 검증이 아니다. 결과는 "가정 모델끼리의 수치 일치 확인"이다.

## 환경별 구현 1 · 채희수: MATLAB (Simulink / Simscape)

**어떻게 구현했나** (5주차 3-2 모델 `w5_stage3_2_joint`를 복사해 단계별로 바꿈)
- **4-3 PWM**: 인버터 자리에 이상적 3상 2레벨 PWM(10 kHz 중심 정렬 삼각 캐리어, min-max 공통모드, 데드타임 0, Vdc 24 V)을 넣은 모델과 평균 모델을 만들었다. 회전축 고정 시험(vq=1 V, 10/20 kHz)과 시작 60 ms 간격 수렴 시험을 함.
- **4-4 열**: PMSM 전기식에 R(T)=0.5[1+0.00393(T−25)]를 넣고, 동손 P=1.5·R·(id²+iq²)를 쌓아 1 ms마다 온도를 갱신(구간 평균 전력 정확해)한다. 열용량 20 J/K, 열저항 10 K/W. 독립 열 시험 3종(10 W 열원, 2 A 정전류, 80 °C 냉각, 600 s)은 연속시간으로, 통합 5종(24 V·0.3 rad / 4 V·2 rad, 25 °C·80 °C 시작)은 2 s로 실행.
- **4-1 건마찰**: 관절 속도를 Simscape 이상 속도원에 넣고 Rotational Friction 블록(Coulomb=Breakaway 0.05 N·m, 점성 0)이 내는 토크를 읽어 관절 입력에 더했다. 블록의 속도 임계값은 민혁 모델에 대응이 없어 0.001 / 0.01 / 0.1 rad/s 세 값으로 민감도를 봤다. 시험 4종(스텝, 작은 스텝, 느린 왕복, 유지 후 재출발).
- **4-2 백래시**: 두 회전 관절을 직렬로 연결(구동 관절 + 회전자 관성 0.0025, 유격 관절의 위치 한계 ±0.5도로 접촉 표현). 점성 0.1은 부하 속도에 외부 토크로 적용. 접촉 강성 1e5/1e6/1e7 N·m/rad × 감쇠 {임계감쇠 근사, 0.01} 6개 설정으로 민감도를 봤다. 시험 3종 + rigid_reference + near_zero_gap.
- **해석 방법**: 가변 스텝, 최대 스텝 5 µs(수렴 확인은 2.5 µs 추가), 평균 인버터(4-3 PWM 제외). 비교 전에 민혁 CSV에 내 지표 함수를 적용해 summary.json 값을 재현하는지 먼저 확인(전부 재현).

**자체 검증**
- 4-4 독립 열 시험: 해석식 대비 최대 온도 오차 5.5e-13 °C(민혁 기준 1e-8).
- MATLAB 자체 간격 수렴: 4-1 5 µs vs 2.5 µs 각도 차 6.9e-9 rad, 4-2 1.2e-7 rad.

## 두 환경 비교 결과 (희수 × 민혁)

판정 기준은 출처를 구분했다. [민혁] 각 단계 README의 수치, [5주차] 각도 1e-3 rad · iq 0.01 A · 관절 토크 0.015 N·m · 모터 토크 0.003 N·m · 정착 0.01 s, [신규] 이번에 새로 정한 기준(사용자 승인 2026-10-11, 하드웨어 정확도 기준 아님). 결과를 보고 기준을 바꾸지 않았다.

| 단계 | 현실 특성 | 통과 / 검사 | 핵심 수치 |
|---|---|---|---|
| 4-3 | 3상 PWM 인버터 | 43 / 43 | MATLAB vs 민혁 PWM 최대 각도 차 6.6e-5 rad, 평균 모델 1.4e-6 rad. 리플 p-p 10 kHz 0.00928 A, 20 kHz 0.00464 A로 민혁과 일치(비 0.5000) |
| 4-4 | 권선 열 | 67 / 67 | 통합 5종 최대 각도 차 baseline 7e-6 rad, stress 2.6e-4 rad. 권선 온도 차 최대 4.9e-6 °C. 2 s 후 온도 25.000644 / 79.453518 °C(24 V), 25.006228 / 79.459722 °C(4 V). 민혁은 25.000644 / 79.453518 / 25.006232 / 79.459727 °C로 차이는 최대 4.9e-6 °C |
| 4-1 | 관절 건마찰 | 56 / 69 | 마찰 없는 baseline 18/18. 속도 임계값 0.001 → 15/16, 0.01 → 16/16, 0.1(블록 기본) → 4/16. 0.3 rad 스텝 최종 오차 MATLAB 0.01257 / 0.01218 / 0.00820 rad, 민혁 0.01251 rad |
| 4-2 | 기어 백래시 | 56 / 109 | rigid 13/13, near_zero_gap 13/13, 자체 수렴 5/5. backlash는 임계감쇠 근사 설정에서 각도는 대부분 통과하나 baseline_step·reversal_steps에서 iq 차(0.014~0.031 A)가 기준 0.01 A 초과. 감쇠 0.01은 접촉이 진동해 크게 어긋남 |

- 4-3과 4-4처럼 두 환경이 같은 식을 푸는 경우는 일치한다.
- 4-1 해석: MuJoCo frictionloss는 제약이라 정지 때도 마찰 한계까지 버티려 하지만 soft constraint라 미세한 잔류 운동이 있을 수 있다. 정지 오차 0.0125 rad(= 0.05/Kp)는 마찰 토크와 위치 P항의 균형으로 예상되는 근삿값이다(민혁 결과 0.01251 rad). Simscape 블록은 속도만의 함수라 정지 때 0이고, 속도 임계값이 작을수록 민혁에 가깝다. 어느 임계값이 맞는지는 알 수 없다.
- 4-2 해석: 유격 폭은 같지만 접촉 모델이 달라 접촉 피크 토크(MATLAB 14.7 vs 민혁 7.9 N·m 등)는 판정에 쓰지 않았다. 유격 안에 머무는 시간은 임계감쇠 근사 설정에서 민혁(0.266 s)과 가깝다(0.270~0.273 s).
- 4-3 해석: 이상적 인버터(데드타임 0, 스위칭 손실 없음) 가정에서 평균 모델과 PWM 모델의 위치 응답 차이는 1.0e-6 rad로 작고 리플은 두 환경이 일치한다. 평균 모델 사용을 설명하는 수치 근거 중 하나일 뿐이다.
- 4-4 해석: 2 s 동작의 자연 온도 상승은 0.0006~0.006 °C로 매우 작다. 80 °C는 가정한 예열 조건이고 이때 최대 iq는 0.684 A로 25 °C(0.708 A)보다 낮다(저항 21.6% 증가).

## 환경별 구현 2 · 이민혁: MuJoCo + 외부 Python
*(희수가 민혁의 README·summary.json·CSV를 기준으로 정리, 민혁 확인 필요)*
- 4-1: MuJoCo 관절 frictionloss 0.05 N·m(soft constraint, solref/solimp는 MuJoCo 기본값). 4-2: MuJoCo 공식 두 hinge 백래시(solref [0.001, 1], solimp [0.99, 0.99, 0.001, 0.5, 2], 반폭 ±0.5도). 4-3: 5주차 평균 인버터를 이상적 3상 2레벨 PWM으로 교체한 시험(별도 보존 코어). 4-4: 외부 Python 열 노드(R(T), C·dT/dt = P−(T−25)/R_th)를 관절·SPMSM과 결합, 열 업데이트 1 ms.
- 단계마다 항목별 PASS/FAIL을 내는 자체 검사를 두었고(4-4는 153개), 모두 PASS로 기록되어 있다. 이 검사들은 MuJoCo 내부 값(운동방정식 잔차, 경고 수 등)을 포함해 MATLAB에서 재현하지 않았다.

## 메모 (한계·미확정)
- 모든 모터·기계·열 파라미터는 가정값이며 하드웨어 검증이 아니다. 마찰 속도 임계값, 접촉 강성·감쇠 값 목록, 임계감쇠 근사 2·sqrt(K·J)는 제안·추정값이고 근거가 되는 실제 데이터가 없다.
- 4-4 열 업데이트 식(구간 평균 전력 정확해)은 처음에 CSV의 1 ms 온도 변화에서 추정했고(오차 1.4e-14 °C), 이후 받은 민혁 `stage4_4_core.py`의 `thermal_step()`과 같은 식임을 코드를 읽어 확인했다. 독립 열 시험은 민혁이 같은 ODE를 RK4(dt 0.1 s)로, MATLAB이 ode45로 적분해 적분기만 다르다.
- MATLAB에서 아직 하지 않은 것: PWM+열 통합(민혁도 안 함), 마찰+백래시 동시 적용, 열 업데이트 0.1 ms 세분 비교와 25/12.5/6.25 µs 수렴(민혁은 MuJoCo에서 이미 확인했고, MATLAB은 가변 스텝이라 4-4에서는 대응하지 않음), 마찰·접촉 공통 힘 계산식을 양쪽에 구현한 추가 비교, MuJoCo 내부 검사의 MATLAB 대응, 4-1·4-2 단독 probe 시험의 MATLAB 대응.
- 시뮬레이터·모터 모델·제어기 선정은 확정이 아니다. 이번 결과는 구현 가능성과 모델 차이를 보여주는 참고 근거이며, 이것만으로 최종 시뮬레이터를 확정하지는 않는다.
- 정정: 4-3 비교 스크립트에서 관절 쪽 토크에 모터 토크 허용치 0.003을 잘못 적용한 것을 0.015(관절)/0.003(모터)로 바로잡았다(결과는 통과로 같음).
