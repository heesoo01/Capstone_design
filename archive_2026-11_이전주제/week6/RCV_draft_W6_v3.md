## 한눈에 보기
- **무엇을 했나**: 민혁이 MuJoCo로 만든 4단계 실험 4가지를 MATLAB에서 같은 조건으로 다시 만들고 결과를 비교했다. 기준 모델은 5주차 3-2이고, 그 모델을 복사해 필요한 곳만 바꿨다.
- **현실 특성 4가지가 뭔가**
  - 4-1 건마찰: 움직임을 막는 일정한 크기의 힘
  - 4-2 백래시: 기어 사이의 헐거운 틈. 방향을 바꿀 때 틈 안에서는 힘이 전달되지 않는다
  - 4-3 PWM: 전압을 아주 빠르게 켰다 껐다 해서 평균 전압을 만드는 인버터. 전류가 조금 떨린다
  - 4-4 열: 전류가 흐르면 권선이 뜨거워지고, 뜨거워지면 저항이 커진다
- **결과**: PWM과 열은 두 환경이 같은 식을 풀어서 결과가 일치했다. 마찰과 백래시는 두 환경이 현상을 다른 방식으로 계산해서 같은 값으로 맞출 수 없었고, 일부 결과가 어긋났다.
- **이 단계의 의미**: 시뮬레이터를 고르기 위한 비교 자료다. 어느 쪽이 더 낫다고 정하지 않고, 현실 특성마다 두 도구가 어떻게 구현하고 어디서 결과가 갈리는지를 파악했다.
- **이 실험의 성격**: 현실의 거친 특성을 모델에 넣어 본 시뮬레이션이다. 실제 모터 데이터로 맞추거나 검증한 것은 아니고, 모든 값은 가정값이다.

## 환경별 구현 1 · 채희수: MATLAB (Simulink / Simscape)

5주차 3-2 모델을 복사해서 단계마다 필요한 부분만 바꿨다.

| 단계 | 바꾼 곳 | 시험 |
|---|---|---|
| 4-3 PWM | 인버터 자리에 10 kHz 3상 PWM을 넣은 모델과 평균 모델. 데드타임 0, Vdc 24 V | 회전축 고정 10/20 kHz, 시작 60 ms 간격 수렴, 통합 2 s |
| 4-4 열 | PMSM 전기식에 R(T)를 넣고 동손을 쌓아 1 ms마다 온도를 갱신. 열용량 20 J/K, 열저항 10 K/W | 독립 열 시험 3종 600 s, 통합 5종 2 s |
| 4-1 건마찰 | 관절 속도로 Simscape 마찰 블록 0.05 N·m가 내는 토크를 읽어 관절에 더함. 속도 임계값 3개로 민감도 확인 | 스텝, 작은 스텝, 느린 왕복, 유지 후 재출발 |
| 4-2 백래시 | 관절 두 개를 직렬로 연결하고 유격 관절의 위치 한계 ±0.5도로 접촉을 표현. 접촉 강성·감쇠 6개 설정 | 스텝, 반복 반전, 느린 왕복. rigid_reference, near_zero_gap과 함께 |

- 비교하기 전에 민혁 CSV에 내 지표 계산을 적용해 summary.json 값이 그대로 나오는지 먼저 확인했다. 전부 재현됐다.
- 자체 검증: 4-4 독립 열 시험은 해석식 대비 최대 온도 오차 5.5e-13 °C. 4-1·4-2는 최대 스텝을 5 µs에서 2.5 µs로 줄여도 각도 변화가 1.2e-7 rad 이하.

## 두 환경 비교 결과 (희수 × 민혁)

| 단계 | 한 줄 결과 | MATLAB 측 통과 / 검사 | 핵심 수치 |
|---|---|---|---|
| 4-3 PWM | 일치 | 43 / 43 | PWM 응답 각도 차 6.6e-5 rad. 전류 리플 10 kHz 0.00928 A, 20 kHz 0.00464 A로 민혁과 같고 주파수를 두 배로 하면 정확히 절반 |
| 4-4 열 | 일치 | 67 / 67 | 권선 온도 차 최대 4.9e-6 °C. 2 s 후 온도 25.000644 / 79.453518 / 25.006228 / 79.459722 °C, 민혁 25.000644 / 79.453518 / 25.006232 / 79.459727 °C |
| 4-1 건마찰 | 속도 임계값에 따라 달라짐 | 56 / 69 | 마찰 없는 baseline은 18/18. 임계값 0.001 → 15/16, 0.01 → 16/16, 0.1 → 4/16. 0.3 rad 스텝 최종 오차 0.01257 / 0.01218 / 0.00820 rad, 민혁 0.01251 rad |
| 4-2 백래시 | 각도는 대체로 일치, 전류·토크는 어긋남 | 56 / 109 | rigid, near_zero_gap, 자체 수렴은 전부 통과. backlash는 iq 차 0.014~0.031 A로 기준 0.01 A 초과. 감쇠 0.01은 접촉이 진동해 크게 어긋남 |

- 통과 개수는 MATLAB 측 비교 검사 항목 수이고 MuJoCo 자체 검사 개수와 대상이 다르다. 단계 사이 통과율을 비교해 모델 정확도를 판단하지 않는다.
- 4-3: 이상적 인버터 가정에서 평균 모델과 PWM 모델의 각도 차이는 MATLAB 1.0e-6 rad, MuJoCo 6.7e-5 rad로 작았다. 이번 조건에서 평균 모델 사용을 설명하는 근거 중 하나이고, 다른 태스크에서도 충분하다는 뜻은 아니다.
- 4-4: 2 s 동작의 자연 온도 상승은 0.0006~0.006 °C로 아주 작다. 80 °C는 가정한 예열 조건이고 이때 최대 iq가 0.684 A로 25 °C의 0.708 A보다 낮다. 저항이 21.6% 커졌기 때문이다.
- 4-1: MuJoCo는 정지해도 마찰 한계까지 버티려 하고 Simscape 블록은 속도가 있어야 마찰이 생긴다. 정지 오차 0.0125 rad는 마찰 토크와 위치 P항이 균형을 이루는 값으로 예상되는 근삿값이다. 속도 임계값이 작을수록 민혁에 가깝지만 어느 값이 맞는지는 알 수 없다.
- 4-2: 유격 폭은 같지만 접촉 모델이 달라서 접촉 순간의 피크 토크는 판정에 쓰지 않았다. 유격 안에 머무는 시간은 임계감쇠 근사 설정에서 0.270~0.273 s로 민혁 0.266 s와 가깝다.

**판정 기준**
- 출처를 나눠 썼다. 민혁 README 수치, 5주차 기준, 이번에 새로 정한 기준이다. 5주차 기준은 각도 1e-3 rad, iq 0.01 A, 관절 토크 0.015 N·m, 모터 토크 0.003 N·m, 정착 0.01 s이다.
- 새 기준은 희수가 2026-10-11에 승인했다. 4-3은 리플 5%, 평균 전압 1e-3 V, 정확해 오차 1e-4 A, 평균 모델 리플 1e-4 A. 4-4는 권선 온도 차 1e-3 °C, 최종 에너지 상대 차 1e-3, 해석식 간 온도 차 2e-8 °C. 4-1과 4-2는 MATLAB 자체 간격 수렴 기준이다.
- 결과를 보고 바꾼 기준은 1건이다. 4-3에서 관절 토크에 모터 토크 허용치 0.003을 잘못 적용했던 것을 0.015로 바로잡았고 통과 결과는 같았다. 나머지 새 기준값은 실행 전에 정한 그대로이고, 승인은 결과를 확인한 뒤에 받았다.

- 이번 결과는 구현 가능성과 모델 차이를 보여주는 참고 근거이고 이것만으로 최종 시뮬레이터를 정하지 않는다.
