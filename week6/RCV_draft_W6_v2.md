## 한눈에 보기
- **무엇을 했나**: 이민혁(MuJoCo)이 만든 4단계 현실 특성 실험 4가지(4-1 관절 건마찰, 4-2 기어 백래시, 4-3 3상 PWM 인버터, 4-4 권선 열 모델)를 MATLAB(Simulink/Simscape)에서 공통 기준 조건에 맞춰 다시 구현하고 결과를 비교했다. 다만 마찰·백래시의 추가 특성은 두 환경의 선택 모델 정의가 달라 완전히 동등한 조건으로 맞추지는 못했다. 기준 모델은 5주차 3-2(기어비 5, 관절 환산 회전자 관성 0.0025)이고, 그 모델을 복사해 필요한 곳만 바꿨다.
- **결과**: 동일한 이상적 전기·열 모델을 대상으로 한 비교(4-3 PWM 43/43, 4-4 열 67/67)는 정한 검사 기준을 모두 통과했다. 정의가 다른 실험(4-1 마찰 56/69, 4-2 백래시 56/109)은 일부 실패했고, 이는 마찰·접촉 모델 자체가 달라 구현 오류와 모델 차이를 구분할 수 없는 부분이다.
- **알게 된 것**: MuJoCo와 Simscape는 마찰(제약 vs 속도 함수)과 접촉(solref/solimp vs 강성·감쇠)을 다르게 모델링해, 선택한 기본 마찰·접촉 모델로는 같은 파라미터 값만으로 동등한 조건이 되지 않는다(공통 힘 계산식을 양쪽에 구현하면 추가 비교는 가능하나 이번에는 하지 않았다). 기어비·관성·제어 조건 등은 공통 기준으로 맞췄다. 마찰·백래시의 추가 특성 중 직접 대응시킨 값은 마찰 크기 0.05 N·m와 유격 반폭 ±0.5도이며, 마찰 전이와 접촉 강성·감쇠는 동등성이 확보되지 않았다.
- **한계**: 모든 값은 가정값이며 하드웨어 검증이 아니다. 결과는 "가정 모델끼리의 수치 일치 확인"이다.

## 환경별 구현 1 · 채희수: MATLAB (Simulink / Simscape)

**어떻게 구현했나** (5주차 3-2 모델 `w5_stage3_2_joint`를 복사해 단계별로 바꿈)
- **4-3 PWM**: 인버터 자리에 이상적 3상 2레벨 PWM(10 kHz 중심 정렬 삼각 캐리어, min-max 공통모드, 데드타임 0, Vdc 24 V)을 넣은 모델과 평균 모델을 만들었다. 회전축 고정 시험(vq=1 V, 10/20 kHz)과 시작 60 ms 간격 수렴 시험을 함.
- **4-4 열**: PMSM 전기식에 R(T)=0.5[1+0.00393(T−25)]를 넣고, 동손 P=1.5·R·(id²+iq²)를 쌓아 1 ms마다 온도를 갱신한다(각 열 업데이트 구간의 평균 동손을 일정 입력으로 둔 1차 RC 열 모델의 해석해 사용). 열용량 20 J/K, 열저항 10 K/W. 독립 열 시험 3종(10 W 열원, 2 A 정전류, 80 °C 냉각, 600 s)은 연속시간으로, 통합 5종(24 V·0.3 rad / 4 V·2 rad, 25 °C·80 °C 시작)은 2 s로 실행. 통합 열·관절 시험에는 평균 인버터를 사용했으며, PWM 스위칭과 열·관절 동작을 동시에 결합한 시험은 하지 않았다.
- **4-1 건마찰**: 관절 속도를 Simscape 이상 속도원에 넣고 Rotational Friction 블록(Coulomb=Breakaway 0.05 N·m, 점성 0)이 내는 토크를 읽어 관절 입력에 더했다. 블록의 속도 임계값은 민혁 모델에 대응이 없어 0.001 / 0.01 / 0.1 rad/s 세 값으로 민감도를 봤다. 시험 4종(스텝, 작은 스텝, 느린 왕복, 유지 후 재출발).
- **4-2 백래시**: 두 회전 관절을 직렬로 연결(구동 관절 + 회전자 관성 0.0025, 유격 관절의 위치 한계 ±0.5도로 접촉 표현). 점성 0.1은 부하 속도에 외부 토크로 적용. 접촉 강성 1e5/1e6/1e7 N·m/rad × 감쇠 {임계감쇠 근사, 0.01} 6개 설정으로 민감도를 봤다. 시험 3종 + rigid_reference + near_zero_gap.
- **해석 방법**: 가변 스텝, 최대 스텝 5 µs(수렴 확인은 2.5 µs 추가), 평균 인버터(4-3 PWM 제외). 비교 전에 민혁 CSV에 내 지표 함수를 적용해 summary.json 값을 재현하는지 먼저 확인(전부 재현).

**자체 검증**
- 4-4 독립 열 시험: 해석식 대비 최대 온도 오차 5.5e-13 °C(민혁 기준 1e-8).
- MATLAB 자체 간격 수렴: 4-1 5 µs vs 2.5 µs 각도 차 6.9e-9 rad, 4-2 1.2e-7 rad.

## 두 환경 비교 결과 (희수 × 민혁)

아래 통과 개수는 MATLAB 측 자체 검사·비교 검사 목록의 항목 수이며, 뒤에 적은 MuJoCo 자체 검사 개수와는 대상과 구성이 다르다. 단계 간 통과율을 직접 비교해 모델의 정확도를 판단하지 않는다.

판정 기준은 출처를 구분했다. [민혁] 각 단계 README의 수치, [5주차] 각도 1e-3 rad · iq 0.01 A · 관절 토크 0.015 N·m · 모터 토크 0.003 N·m · 정착 0.01 s, [신규] 이번에 새로 정한 기준(하드웨어 정확도 기준 아님).

- **승인**: [신규] 기준은 사용자(채희수)가 2026-10-11 대화에서 승인했다. 기록은 RAMS `decisions/d20261011b`와 각 비교 스크립트(`w6s43~44_compare.py`, `w6s41~42_compare.py`)의 기준 출처·승인 문구이다. 4-3은 네 개(리플 5%, 평균 전압 1e-3 V, 정확해 오차 1e-4 A, 평균 모델 리플 1e-4 A), 4-4는 세 개(권선 온도 차 1e-3 °C, 최종 에너지 상대 차 1e-3, 해석식 간 온도 차 2e-8 °C), 4-1·4-2는 MATLAB 자체 간격 수렴 기준(민혁 README의 MuJoCo dt 수렴 수치를 재사용)이다.
- **기준을 결과를 본 뒤 바꿨는가**: 바꾼 것은 1건이다. 4-3 비교 스크립트에서 관절 쪽 토크에 모터 토크 허용치 0.003을 잘못 적용했던 것을 0.015(관절)/0.003(모터)로 정정했다(사용자 승인, 통과 결과는 같음). 그 밖의 [신규] 기준값은 실행 전에 스크립트에 정해 둔 값 그대로이며 결과를 보고 바꾸지 않았다. 다만 4-4와 4-1·4-2의 [신규] 기준은 값은 실행 전에 정했지만 승인은 결과를 확인한 뒤였다.

- 4-3과 4-4의 이번 시험 조건에서는 두 환경의 동일한 가정 모델이 정한 비교 기준 안에서 일치했다. 모든 운전 조건에서 일치함을 증명한 것은 아니다.
- 4-1 해석: MuJoCo frictionloss는 제약이라 정지 때도 마찰 한계까지 버티려 하지만 soft constraint라 미세한 잔류 운동이 있을 수 있다. 잔류 위치 오차 0.0125 rad(= 0.05/Kp)는 마찰 토크와 위치 P항의 균형으로 예상되는 근삿값이다(민혁 결과 0.01251 rad). Simscape 블록은 속도만의 함수라 정지 때 0이고, 속도 임계값이 작을수록 민혁에 가깝다. 어느 임계값이 맞는지는 알 수 없다.
- 4-2 해석: 유격 폭은 같지만 접촉 모델이 달라 접촉 피크 토크(MATLAB 14.7 vs 민혁 7.9 N·m 등)는 판정에 쓰지 않았다. 유격 안에 머무는 시간은 임계감쇠 근사 설정에서 민혁(0.266 s)과 가깝다(0.270~0.273 s).
- 4-3 해석: 이상적 인버터(데드타임 0, 스위칭 손실 없음) 가정에서 각 환경 내 평균 모델과 PWM 모델의 최대 각도 차이는 MATLAB 약 1.0e-6 rad, MuJoCo 약 6.7e-5 rad였다. 이번 시험 조건에서는 두 환경 모두 관절 위치 응답 차이가 작았으며, 회전축 고정 시험의 PWM 전류 리플은 비교 기준 안에서 일치했다. 이 결과는 이번 조건에서 평균 모델 사용을 설명하는 근거 중 하나이며, 다른 태스크에서도 평균 모델로 충분하다는 결론은 아니다.
- 4-4 해석: 2 s 동작의 자연 온도 상승은 0.0006~0.006 °C로 매우 작다. 80 °C는 가정한 예열 조건이고 이때 최대 iq는 0.684 A로 25 °C(0.708 A)보다 낮다(저항 21.6% 증가).

## 환경별 구현 2 · 이민혁: MuJoCo + 외부 Python
*(희수가 민혁의 README·summary.json·CSV를 기준으로 정리, 민혁 확인 필요)*
- 4-1: MuJoCo 관절 frictionloss 0.05 N·m(soft constraint, solref/solimp는 MuJoCo 기본값). 4-2: MuJoCo 공식 두 hinge 백래시(solref [0.001, 1], solimp [0.99, 0.99, 0.001, 0.5, 2], 반폭 ±0.5도). 4-3: 5주차 평균 인버터를 이상적 3상 2레벨 PWM으로 교체한 시험(별도 보존 코어). 4-4: 외부 Python 열 노드(R(T), C·dT/dt = P−(T−25)/R_th)를 관절·SPMSM과 결합, 열 업데이트 1 ms.
- **4-1 검증**: 마찰 유무에 따른 응답, 작은 토크에서의 잔류 운동, 운동방정식 잔차와 마찰 일을 확인했다. 자체 검사 107개 PASS.
- **4-2 검증**: 유격 구간의 토크 전달, 회전 방향 전환 시 접촉 토크, 운동방정식과 시간 간격 세분화에 따른 수렴을 확인했다. 접촉 피크 토크는 시간 간격에 민감하므로 점별 피크의 완전한 일치를 요구하지 않았다. 자체 검사 152개 PASS.
- **4-3 검증**: 스위칭 전압, 좌표변환과 전력식, 독립 전기 모델과의 대조, 전류 리플, 시간 간격 수렴을 확인했다. 자체 검사 97개 PASS.
- **4-4 검증**: 온도에 따른 저항 변화, 독립 열 해석식과의 대조, 통합 에너지 수지, 전기·기계 시간 간격 및 열 업데이트 간격 세분화 영향을 확인했다. 자체 검사 153개 PASS. 통합 열·관절 시험은 평균 인버터이며, 별도로 회전자 고정·정상 주기 조건의 PWM 동손을 확인했다.
- 위 자체 검사는 MuJoCo 내부 값(운동방정식 잔차, 경고 수 등)을 포함하며, MATLAB 측 비교 검사 목록과 일대일로 대응하지 않는다. 모두 PASS라는 것은 가정 모델과 설정한 검사 기준의 충족을 뜻하며 하드웨어 검증은 아니다. (검사 개수 107/152/97/153은 각 `summary.json`의 `tests`를 직접 세어 확인했다.)

- 4-4 열 업데이트 식(구간 평균 동손을 일정 입력으로 둔 RC 열 모델의 해석해)은 처음에 CSV의 1 ms 온도 변화에서 추정했고(오차 1.4e-14 °C), 이후 받은 민혁 `stage4_4_core.py`의 `thermal_step()`과 같은 식임을 코드를 읽어 확인했다. 독립 열 시험은 민혁이 같은 ODE를 RK4(dt 0.1 s)로, MATLAB이 ode45로 적분해 적분기만 다르다.
- 네 특성은 단계별로 따로 시험했으며, 마찰·백래시·PWM·열을 모두 동시에 적용한 통합 시험은 하지 않았다.
- MATLAB에서 아직 하지 않은 것: PWM+열 통합(민혁도 안 함), 마찰+백래시 동시 적용, 열 업데이트 0.1 ms 세분 비교와 25/12.5/6.25 µs 수렴(민혁은 MuJoCo에서 이미 확인했고, MATLAB은 가변 스텝이라 4-4에서는 대응하지 않음), 마찰·접촉 공통 힘 계산식을 양쪽에 구현한 추가 비교, MuJoCo 내부 검사의 MATLAB 대응, 4-1·4-2 단독 probe 시험의 MATLAB 대응.
- 이번 실험에는 가정 파라미터의 SPMSM과 위치 PD·전류 PI를 사용했다. 최종 주 시뮬레이터, 실제 사용할 모터·드라이버 제품 및 파라미터, 최종 태스크용 제어기의 선정은 확정이 아니다. 이번 결과는 구현 가능성과 모델 차이를 보여주는 참고 근거이며, 이것만으로 최종 시뮬레이터를 확정하지는 않는다.
- 정정: 4-3 비교 스크립트에서 관절 쪽 토크에 모터 토크 허용치 0.003을 잘못 적용한 것을 0.015(관절)/0.003(모터)로 바로잡았다(결과는 통과로 같음).
