## 0. 한 문장 요약
"진짜 모터와 감속기를 단 로봇팔은, 토크를 마음대로 낼 수 있다고 가정한 로봇팔에 비해 공을 얼마나 덜 정확하게 던지나?"를 시뮬레이션으로 재는 프로젝트로 바뀌었다. 민혁은 그중 **모터(단계 1) → 액추에이터 틀(단계 2) → 로봇 쪽 꽂을 자리(단계 3 준비)** 까지 만들어 두었다.

## 1. 예전 주제와 뭐가 달라졌나
| | 예전 (10월까지) | 지금 |
|---|---|---|
| 대상 | 특정 로봇 없는 1자유도 관절 | **Kinova Gen3 7축 로봇팔**의 관절 2 (어깨 쪽) |
| 모터 | 가정값 PMSM (Kt 0.3, 기어 5) | **실제 상용 부품** 데이터시트: maxon EC-i 52 모터 + 하모닉 드라이브 1:100 |
| 비교 | MuJoCo vs MATLAB (시뮬레이터끼리) | **이상 토크 vs 실제 액추에이터** (같은 로봇에서) |
| 모터 구현 | Simscape 블록 | 식을 블록으로 **직접 구현** (교수님 피드백 "딸깍 하지 마라") |

## 2. 전체 그림: 신호가 어떻게 흐르나
```
궤적(던지기 동작) → CTC(위치 제어기) → [관절 2 액추에이터] → Gen3 로봇팔 → 각도·속도 → 다시 CTC
                                       │
                         토크→전류 변환 → FOC(전류 제어) → PMSM 모터 → 모터축 → 감속기(스프링) → 관절 토크
```
- **CTC(Computed Torque Control)**: 로봇의 운동방정식을 알고 "이 동작을 하려면 관절마다 토크가 얼마 필요한지" 계산하는 제어기다. 예전 "이상 토크" 모델은 이 토크가 그대로 관절에 들어간다고 가정했다.
- 이제 관절 2에만 **진짜 액추에이터**를 끼운다. 그러면 토크가 늦게 나오거나, 전류·전압 한계에 걸리거나, 감속기가 스프링처럼 출렁인다. 그 차이를 재는 게 목표다.

## 3. 단계 1: 모터를 직접 만들었다 (완료)
**무엇:** PMSM 모터의 dq 전압 방정식을 Gain·Sum·Integrator 블록으로 하나하나 짰다(`PMSM_dq_manual`). 전류를 원하는 값으로 맞추는 FOC 제어기(`FOC_current_ctrl`)도 직접 짰다.

**비유:** 라이브러리 모터 블록은 "완제품 엔진", 직접 구현은 "엔진을 부품부터 조립"한 것이다. 조립이 맞는지 확인하려고 완제품(동하의 Simscape PMSM 모델)과 같은 조건으로 나란히 돌려 봤다.

**결과:**
| 비교 | 차이 |
|---|---|
| 직접 만든 모터 vs Simscape PMSM 블록 | 전류 iq 최대 0.00035 A, 속도 0.000032 rad/s → 사실상 같다 |
| dq 모델 vs 독립 3상 모델 (Python) | 0.0000025 A |
| 시험 9개 항목 | 전부 통과 (전류 상승 0.35 ms 등) |

**동하 FOC와 새 FOC의 차이** (동하용 PDF 11/18 내용):
| | 동하 | 새 FOC | 의미 |
|---|---|---|---|
| 전류 루프 대역폭 | 약 159 Hz | 1 kHz | 토크가 약 6배 빨리 따라온다(상승 2.2 ms → 0.35 ms) |
| 디커플링 | 역기전력만 보상 | d·q 결합 항 전부 미리 뺌 | 빠르게 돌 때 d축과 q축이 서로 간섭하는 걸 막는다 |
| 전압 제한 | 축마다 ±12 V (사각형) | 벡터 크기 ≤ 12.47 V (원형) | 실제 인버터는 벡터 크기로 제한된다. 사각형이면 못 만드는 17 V까지 허용해 버린다 |
| 파라미터 | 수업 예제값 추정 | maxon 데이터시트 | 실제 부품 기준 |

결론: 동하 구조는 맞았다. 새 FOC는 거기에 실제 인버터 한계와 실제 모터 값을 넣은 것이다.

## 4. 기준 사양: 왜 이 모터·감속기·전압인가
`docs/03_관절2_기준사양_결정.md` 내용이다.
1. 먼저 기존 던지기 시뮬레이션(이상 토크)에서 **관절 2가 실제로 얼마를 요구하는지** 뽑았다. 피크 토크 29.75 N·m, 최대 속도 2.7 rad/s, 최대 출력 68 W.
2. 그 요구량을 만족하는 maxon 모터 × 하모닉 감속비 조합을 비교해서 골랐다.
3. **전원 24 V**: Gen3 공식 전원이 24 V(허용 18–30 V)라서다. 48 V로 하면 전압 여유가 너무 커서 "전압 한계 영향"이 안 보인다.
4. **전류 한계 두 가지**: 20.9 A(정격의 2배, 짧은 던지기에서 열 여유가 큼)와 10.4 A(모터가 뜨거워져 드라이브 보호가 걸린 상태 흉내).
5. 이걸로 시험 사례 3개를 만든다: **A-24**(24 V, 20.9 A), **B-24**(24 V, 10.4 A), **A-18**(18 V로 전압 떨어진 경우).

⚠ 주의할 점: 던지기 궤적은 관절 2에 2.7 rad/s를 요구하는데, Gen3 실제 액추에이터 최대 속도는 약 1.36 rad/s다(약 2배 초과). 그래서 교수님 말대로 **느린 동작부터** 시작한 것이다.

## 5. 단계 2: 액추에이터 블록 틀 (민혁이 틀 완성, 동하가 다듬는 중)
**무엇:** 단계 1 모터에 감속기와 모터축을 붙여 블록 하나(`J2_Actuator`)로 만들었다. 입력 3개(토크 명령, 관절 각도, 관절 속도), 출력 1개(관절 토크)다.

**안에 든 것 5개:**
1. 토크 → 전류 명령: iq = 토크 / (s·N·Kt)
2. FOC (단계 1 그대로)
3. dq 모터 (단계 1 그대로)
4. 모터축: 회전자 + 웨이브 제너레이터 관성
5. 감속기 비틀림 스프링: 감속기를 **아주 뻣뻣한 스프링**으로 본다(Kg = 14000 N·m/rad)

**1자유도 시험 결과 (12개 항목 모두 통과, Python 기준과 일치):**
| 시험 | 결과 | 쉽게 말하면 |
|---|---|---|
| T1 관절 고정, 10 N·m | 최종 10 N·m, **순간 피크 18.6 N·m** | 감속기 스프링 + 회전자가 약 38 Hz로 출렁인다. 감쇠가 작아서 1.86배까지 튄다 |
| T2 부호 반대(s=+1) | 관절 토크 동일, 전류 부호만 반대 | 부호 처리가 맞다는 확인 |
| T3 100 N·m 요구 | 전류 20.9 A에서 잘림 → 91.2 N·m만 나옴 | 전류 한계가 토크 상한을 만든다 |
| T4 진자 (1.2 kg·m²) | 이상 토크보다 22.3 mrad 뒤처짐 | 회전자 관성(관절 기준 0.249 kg·m², 부하의 약 21%)을 더 돌려야 해서 덜 가속된다 |
| T4b 진자 + 관성 보상 | 0.08 mrad로 줄어듦 | 명령에 회전자 몫 토크를 미리 더하면 해결된다 → CTC의 `ctc_Jr` 옵션 |

⚠ **중요한 발견:** 100 N·m 계단 명령에서는 감속기 토크가 순간 약 170 N·m까지 튄다. 감속기 순간 한계 125 N·m를 넘는다. 실제 던지기 명령은 부드럽지만, **던지기 릴리스·감속 구간에서 감속기 토크 피크를 꼭 확인해야 한다.**

## 6. 단계 3 준비: 로봇에 꽂을 자리 (완료)
| 한 일 | 결과 | 의미 |
|---|---|---|
| 관절 2 슬롯 만들기 | 원본과 차이 0 | 빈 자리를 만들어도 로봇 동작이 안 바뀐다. 이제 안만 바꾸면 된다 |
| 느린 point-to-point 동작 | 관절 2 +0.8 rad, 관절 4 −0.8 rad, 3초 이동, 피크 속도 0.5 rad/s (한계의 37%) | "던지기 전에 움직이는 것부터" |
| 관성 변화 분석 | 관절 2가 느끼는 관성 M22가 동작 중 13% 변함, 관절 4 결합 M24는 최대 35% | 교수님이 말한 "관절 사이 관성 변화"를 숫자로 보였다. 감속비 100으로도 결합이 안 숨는다 |
| **오차 원인 찾기** | 이상 토크인데도 오차가 남았던 이유 = **CTC가 손에 쥔 공(0.1 kg)을 몰랐다** | 공을 알려 주니 느린 동작 오차 20.8 → 0.022 mrad, 던지기 159.9 → 0.026 mrad |
| CTC에 반사 관성 옵션 | `ctc_Jr = [0 0.249 0 0 0 0 0]'` 로 켬 | 액추에이터를 꽂을 때 켠다 (T4b와 같은 원리) |

⚠ **중요:** 예전 "이상 토크 baseline" 던지기 결과에는 공 질량 문제로 손목 오차 약 9°가 섞여 있었다. **앞으로 기준선은 페이로드 CTC 모델(`Gen3_J2_ctc`)로 바꾼다.**

## 7. 아직 안 된 것 (다음 할 일)
1. 동하: 단계 2 액추에이터 다듬기 → `J2_Actuator.slx` + 시험 결과 + 바꾼 점 한 문단 전달
2. 민혁(+Claude): `Gen3_J2_ctc.slx`에 꽂아 `Gen3_J2_act.slx` 만들기 → 느린 동작에서 이상 토크(0.022 mrad)와 비교
3. 던지기 + 사례 A-24 / B-24 / A-18 → 릴리스 속도, 착지 위치, 감속기 토크 피크 비교
4. 관절 4 → 관절 1로 확장
5. 아직 모델에 없는 것: 감속기 효율·마찰, 회생 전력 처리(DC 링크), 보호 기능(I²t). 문서에 "이후 과제"로 적혀 있다

## 8. 용어 미니 사전
| 용어 | 뜻 |
|---|---|
| dq 좌표 | 3상 교류를 회전자와 같이 도는 좌표로 바꾸면 직류처럼 보인다. d=자속 방향, q=토크 만드는 방향 |
| FOC | dq 좌표에서 전류를 PI로 제어하는 방법. id=0, iq로 토크 조절 |
| 역기전력 | 모터가 돌면 발전기처럼 생기는 반대 전압. 빠를수록 커서 전압 여유를 잡아먹는다 |
| 반사 관성 Jr | 모터 회전자 관성이 감속기를 거치면 N²배로 커져 보인다. 100² × 2.49e-5 = 0.249 kg·m² |
| 비틀림 강성 Kg | 감속기를 스프링으로 봤을 때 1 rad 비틀려면 필요한 토크 |
| 페이로드 | 로봇이 든 물체(공). 제어기가 알아야 중력을 정확히 보상한다 |
| mrad | 0.001 rad ≈ 0.057° |

## 9. 민혁에게 물어볼 만한 것
- 희수 담당은 무엇으로 할지 (예: 사례 A-24/B-24/A-18 실행·분석, 관절 4 액추에이터, 발표 자료)
- `baseline_input_decel.mat`와 Gen3 모델 실행 파일을 공유받을 수 있는지 (단계 3·4 재실행에 필요)
- MATLAB 버전(민혁 R2026b, 희수 PC R2026a)에서 `.slx`가 열리는지
- 진행 계획 문서("Week12 진단 및 진행 계획") 공유 링크
