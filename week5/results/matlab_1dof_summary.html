MATLAB Simscape 1자유도 액추에이터 검증 요약

종합설계 5주차 · 환경: MATLAB R2026a (Simulink, Simscape, Simscape Multibody / Driveline / Electrical) · 모델 파일: week5/scripts/s1_mechanical.slx

1. 무엇을 검증했나

1자유도 회전 관절 하나에 구동 체인(토크원 → 감속기 → 회전마찰)과 PID 위치제어를 붙인 폐루프 시뮬레이션이다. 질량·관성은 구성 요소 중 하나일 뿐이다. 목적은 시뮬레이터 확정이 아니라 "이 구조(Pick-and-Place 시나리오)가 Simscape에서 구현 가능한가"를 확인하는 테스트다.

2. 시나리오와 입력

항목내용비교 메모
형상수직면 진자형 1관절. 회전축 = 수평(월드 Y), 링크는 +X 방향 0.3 m, 중력 −Z. q=0°는 팔이 수평인 자세 (q=90°가 위/아래인지 부호는 미확인)
목표각 입력0° → 30° (t=0.5 s) → 60° (t=2.5 s) → 90° (t=4.5 s), 30°씩 계단 입력
부하 변화 입력점질량 0.5 kg → 0.7 kg (t=2.0 s, Pick) → 0.5 kg (t=6.0 s, Place). 한 번의 연속 시뮬레이션에서 변화
시뮬레이션 시간8 s, Simulink 가변 스텝 (MaxStep = auto)

3. 구조 (신호 흐름)

목표각 − 현재각(관절 위치 센싱, deg) → PID → 부호반전(−1) → 이상적 토크원(모터 대용) → 감속기 50:1 → 회전마찰 → Rotational Multibody Interface → 회전 관절 → 링크 → 점질량(시변)

감속기 출력축 방향이 opposite라 PID 출력에 −1을 넣어야 안정했다 (넣지 않으면 발산).

5. 결과

항목관찰비교 메모

6. 한계 (비교 시 유의)

  • 모터는 이상적 토크원: PMSM, 인버터, 전류루프, 로터 관성 없음. 감속기에도 관성·효율 없음.
  • 모든 값은 가정값이며 하드웨어 미정. 쿨롱 마찰 0.001은 0이면 에러가 나서 넣은 최소값.
  • 백래시는 비활성: 켜면 초기조건 수렴이 실패해 보류.
  • PID 게인은 튜닝하지 않은 값 (발산 방지용으로 낮춤).
  • 정량 지표 미산출: Settling time, Overshoot, SSE, RMSE, Control effort는 그래프로만 확인. 비교 시 같은 지표로 재산출 필요.
  • 질량 변화는 이상화: 점질량의 질량값만 시간에 따라 변경, 형상·관성 텐서는 고정.
