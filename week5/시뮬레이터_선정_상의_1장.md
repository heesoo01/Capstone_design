# 시뮬레이터 선정 상의 (1장) — 2026-10-04, 채희수

> 결정된 것이 아니라 상의용 정리다. 아래 내용 중 "확인된 것"은 우리 실험 결과이고, "아직 모르는 것"은 조사 전이다.

## 1. 지금까지 확인된 것 (우리 실험)
- 같은 가정 모델(1관절, PMSM + 전류 PI + 평균 인버터, 기어비 5, 회전자 관성)을 MATLAB(Simulink/Simscape)과 MuJoCo(+외부 Python PMSM)에 각각 구현해 단계별로 비교했다: 1단계, 2-1, 2-2, 2-3, 3-1, 3-2, 3-3 전부 잠정 기준 PASS (최대 각도 차 7.2e-6 rad, iq 차 3.1e-4 A, 관절 토크 차 4.6e-4 N·m).
- 의미: 이 단순한 범위에서는 **두 환경이 같은 결과**를 낸다. 즉 이 범위만으로는 두 환경을 구분하지 못했고, 우리 구현에 숨은 실수도 없었다.
- 한계: 모터·인버터는 양쪽 모두 우리가 직접 구현했다(MuJoCo에는 기본 PMSM이 없어 외부 Python 연결). 값은 모두 가정값. PWM·스위칭·보호·DC 링크·기어 마찰·백래시·접촉은 아직 없다.

## 2. 아직 모르는 것 (조사·실험 필요)
- 교수님 질문 "이미 잘 만들어진 시뮬레이터는 없는가": MATLAB·MuJoCo 외에 액추에이터 특성이 이미 들어 있는 시뮬레이터/툴박스가 있는지 **조사 안 함** (`docs/simulator-survey.md` 미작성).
- 현실 특성(PWM, 마찰, 백래시, 열 등)을 각 환경에서 얼마나 쉽게 넣을 수 있는가.
- 태스크가 확정되지 않았다. 던지기처럼 접촉이 많아지면 접촉 동역학이 중요해져 선택이 달라질 수 있다.

## 3. 정해야 하는 이유
1. 교수님이 "기존 시뮬레이터가 있는가"를 물으셨으므로, 직접 구현을 정당화하거나 기존 것을 쓸 근거가 필요하다.
2. 두 환경을 끝까지 같이 유지하면 태스크·제어기·평가를 두 번씩 해야 한다.
3. 태스크 선택에 따라 유리한 환경이 달라질 수 있다.
- 참고: 9/29 교수님 피드백 기록은 "MATLAB 먼저 모델링하고 부족하면 MuJoCo로 이식 조사".

## 4. 선택지

| A | MATLAB 주 + MuJoCo 보조(이식 가능성만 확인) | 9/29 피드백 방향과 일치, 일의 양 적음 | 접촉 위주 태스크가 되면 재검토 필요 |

2. (교수님) 태스크를 어렵게 고도화하는 방향(예: 던지기)이면, 시뮬레이터 선택을 태스크 결정 뒤로 미뤄도 되는가?
