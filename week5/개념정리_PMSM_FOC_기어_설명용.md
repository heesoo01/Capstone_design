# 우리가 한 것 개념 정리 (팀이 직접 설명할 수 있게)

> 목적: 1~3단계에서 만든 모델을 팀원 모두가 말로 설명할 수 있게 한다. 숫자는 모두 우리 가정값이고 실제 하드웨어 값이 아니다.
> 수식과 개념은 전동기 제어 교재 수준의 일반적인 내용이다. 보고서에 쓸 때는 교재·논문 출처를 `docs/references.md`에 추가해야 한다 (아직 안 함).
> 이 문서는 AI(Claude Code)가 정리했다. 읽으면서 "내 말로 설명해 보기"를 꼭 해 보자 (10절 질문 연습).

## 0. 한 장 요약

```
위치 명령 → [위치 PD, 1 ms] → 필요한 관절 토크 → ÷(N·Kt) → 전류 지령 iq*
   → [전류 PI, 100 µs] → 전압 v → [전압 제한] → (평균 인버터) → PMSM → 모터 토크 Tm = Kt·iq
   → [기어 ×N] → 관절 토크 → 관절(관성 J, 감쇠 b) → 관절 각도 q (다시 위치 PD로)
```

- 한 줄: **"관절을 움직이려면 토크가 필요하고, 모터는 토크를 전류로 만든다. 전류는 전압으로 만든다."** 그래서 제어도 바깥(위치) → 안쪽(전류) → 전압 순서로 겹쳐 있다.
- 우리가 한 일: 이 체인을 MATLAB과 MuJoCo에 각각 만들어 같은 입력에서 같은 출력이 나오는지 확인했다 (1단계 → 2단계 → 3단계로 부품을 하나씩 추가).

## 1. 모터는 왜 "전류 = 토크"인가
- 표면부착형 PMSM(영구자석 동기 전동기)에서 토크는 거의 `Tm = Kt · iq` (iq = 토크를 만드는 전류).
- 우리 값: 극쌍 p = 4, 자속 ψ = 0.05 Wb → `Kt = 1.5 · p · ψ = 0.3 N·m/A`.
- 예: iq = 2 A이면 모터 토크 0.6 N·m. 전류 지령을 ±2 A로 제한하면 모터 토크도 ±0.6 N·m로 제한된다.
- 그래서 제어기는 "토크를 내라"가 아니라 "iq를 이만큼 흘려라"를 명령한다.

## 2. dq 좌표 (PMSM 식이 왜 이렇게 생겼나)
- 실제 모터는 3상 교류(a, b, c)로 구동한다. 회전자와 같이 도는 좌표(d, q)에서 보면 교류가 직류처럼 보여서 PI 제어를 쓰기 쉽다. 이 변환이 Clarke → Park (동하 모델의 MATLAB Function 블록이 하는 일).
- d축 = 자석이 향한 방향(자속 방향), q축 = 거기에 수직(토크를 만드는 방향). `id = 0`으로 두는 것이 우리 기본 설정이다 (자속 방향으로는 토크가 안 나오므로).
- 전기 방정식 (우리 모델, Ld = Lq = L):
  - `L·d(id)/dt = vd − R·id + we·L·iq`
  - `L·d(iq)/dt = vq − R·iq − we·(L·id + ψ)`
  - `we = p · wm` (전기 각속도 = 극쌍 × 모터 기계 속도)
- 각 항의 뜻: `R·i`는 저항 전압강하, `we·ψ`는 **역기전력**(모터가 빨리 돌수록 커지는, 전압을 방해하는 항), `we·L·i`는 d·q가 서로 영향을 주는 교차항.
- 우리 값: R = 0.5 Ω, L = 5 mH. 전기 시간상수 L/R = 10 ms.

## 3. 전류 제어 (PI + 전향 보상)
- 목표: id → 0, iq → iq* 가 되도록 vd, vq를 정한다 (100 µs마다 계산).
- `e = [−id, iq* − iq]`, `v = Kp·e + I + ff`
  - PI: Kp = 1.5 V/A, Ki = 150 V/(A·s).
  - `ff = [−we·L·iq, we·(L·id + ψ)]` : 역기전력과 교차항을 **미리 계산해서 상쇄**하는 항(전향 보상). 이게 없으면 모터가 빨라질수록 PI가 혼자 따라가야 해서 느리다.
- 계산한 전압은 다음 100 µs 동안 유지된다 (샘플-유지).

## 4. 전압 제한과 안티윈드업 (2 V 실험의 의미)
- 인버터가 낼 수 있는 전압에는 한계가 있다: `Vlimit = Vdc/√3`. 24 V → 13.856 V, 2 V → 1.155 V.
- 요청 전압이 한계보다 크면 **방향은 유지하고 크기만** 한계로 줄인다.
- 문제(윈드업): 전압이 막혀 있는데 적분기가 계속 쌓이면, 한계가 풀릴 때 과하게 튄다. 해결(안티윈드업): 적분기에 `Kaw·(제한된 전압 − 요청 전압)`을 되먹임 (우리 Kaw = 300 s⁻¹).
- 2 V 실험은 일부러 전압을 모자라게 해서 **전압 포화 현상**을 보려는 극단 조건이다. 3-1 기준 0.200~1.728 s 동안 포화되고, 전류가 지령(2 A)에 못 미쳐 최대 1.45 A, 목표 2 rad에 2초 안에 도달하지 못한다(최종 약 1.905 rad). 두 환경이 이 포화 구간까지 똑같이 맞았다는 점이 중요하다.

## 5. 위치 제어와 전류 지령
- 위치 PD (1 ms마다): `τ_req = Kp(q_ref − q) − Kd·qdot` (Kp = 4, Kd = 1). "목표와의 거리에 비례해서 토크를 내고, 속도에 비례해서 브레이크를 건다."
- 전류 지령 변환: `iq_raw = τ_req / (N·Kt)`, `iq* = clip(iq_raw, ±2 A)`.
  - 0.3 rad 스텝 (기어비 5): τ_req = 4 × 0.3 = 1.2 N·m → iq_raw = 1.2/1.5 = 0.8 A (제한 안 걸림).
  - 2 rad 스텝: τ_req = 8 N·m → iq_raw = 5.33 A → **2 A로 제한** (전류 지령 제한). 이때 관절 토크는 최대 N·Kt·2 = 3 N·m.
- 참고: 전류 지령 제한은 실제 전류를 강제로 자르는 보호 회로가 아니라 "지령값"을 제한하는 것이다.

## 6. 평균 인버터 (PWM을 안 쓰는 이유와 한계)
- 실제 인버터는 스위치를 빠르게 켜고 끄는 PWM으로 전압을 만든다. 우리는 "원하는 전압이 평균적으로 그대로 나온다"고 가정한 **평균 전압 모델**을 쓴다. 계산이 가볍고 제어 성능 비교에 충분하다.
- 한계(모델에 없는 것): 스위칭 리플, 데드타임, 스위치 손실, 보호 동작, DC 링크 전압 변동. 교수님 피드백(9/29)도 "평균 모델이 충분한 근거를 설명하라"였다.

## 7. 기어와 회전자 관성 (3단계에서 바뀐 것)
기어비 정의: `N = 모터 속도 / 관절 속도 = 5`. 이상 기어(효율 100 %, 마찰·백래시·탄성 없음).

기어를 넣으면 **세 곳**이 바뀐다 (README의 "5배를 두 번 적용하지 마세요"가 이것이다).
1. 전류 지령: `iq_raw = τ_req/(N·Kt)` → 같은 관절 토크에 전류는 1/5만 필요.
2. 모터 속도: `wm = N·wj` → **역기전력은 모터 속도로 계산**하므로 같은 관절 속도에서 역기전력이 5배.
3. 관절 입력 토크: `Tj = N·Tm`.
위치 PD는 계속 관절 각도·속도를 쓴다.

회전자 관성 (3-2):
- 모터축 관성 Jm = 1e-4 kg·m². 관절에서 보면 `N²·Jm = 25 × 1e-4 = 0.0025 kg·m²` 로 보인다.
- 왜 N²인가: 모터가 N배 빨리 돌므로 운동에너지 `½·Jm·wm² = ½·Jm·N²·wj²`. 관절 쪽에서 보면 관성이 N²배로 커진 것과 같다.
- 총 관절 관성 `J = J_링크 + N²·Jm = 0.0535417 + 0.0025 = 0.0560417 kg·m²` (약 4.7 % 증가).
- **중복 주의**: 모터축 관성을 따로 넣고 환산 관성도 넣으면 두 번 더하는 것이다. 우리는 "환산 관성을 관절 관성에 한 번만 가산"하는 방식 하나만 썼다. 감쇠 0.1도 관절에서 한 번만.
- 단독 검사로 확인: 모터 토크 0.02 N·m를 직접 넣으면 관절 토크 `N × 0.02 = 0.1 N·m`, 초기 가속도 `0.1/J` = 3-1 1.8677 rad/s², 3-2 1.7844 rad/s² (비율 0.9554 = J_링크/J_합계).

회전자 관성을 넣었더니 24 V 정착이 소폭 빨라진 이유(간단한 설명):
- 위치 루프만 보면 `J·q̈ + (b+Kd)·q̇ + Kp·q = Kp·q_ref` 형태이고, 우리 값(b+Kd = 1.1, Kp = 4)에서는 감쇠비 ζ ≈ 1.19로 과감쇠다. 느린 극점이 J = 0.05354에서 −4.72, J = 0.05604에서 −4.82로 **오히려 약간 빨라진다** (계산: `s = [−c ± √(c²−4JKp)]/(2J)`). 정착이 0.904 → 0.894 s로 줄어든 방향과 같다.
- 이것은 "관성이 늘면 반드시 느려진다"가 틀릴 수 있음을 보여 주는 예이고, 제어 이득이 고정일 때의 결과다 (전류 루프 포함 전체 응답은 두 환경 시뮬레이션이 직접 보여 준다).

## 8. 두 환경에서 어떻게 구현했나
| | MATLAB (희수) | MuJoCo (민혁) |
|---|---|---|
| 관절·강체 | Simscape Multibody 관절(회전, 관성, 감쇠) | MuJoCo 관절(implicitfast) |
| PMSM·PI·전압 제한 | Simulink 표준 블록(Integrator, Gain, ZOH 등) | 외부 Python (RK4) |
| 적분 | 가변 스텝 ode23t (RelTol 1e-6, AbsTol 1e-9), 간격 상한 25/12.5/6.25 µs | 고정 간격 25/12.5/6.25 µs |
| 연결 | 한 모델 안에서 연속 계산 | 매 구간 시작 속도로 전기를 계산하고, 시작 전류의 토크를 그 구간 동안 관절에 유지 |
- 둘 다 같은 제어 순서: 측정 → (해당 시점이면) 위치 PD → 전류 PI → 전압 제한 → PI 적분 상태 갱신. 위치와 전류 갱신이 동시에 일어나면 위치가 먼저.
- 동하의 Simscape Electrical 모델은 별개의 PMSM+FOC 구현(3상 전압원, Clarke/Park, d·q PI, ±12 V 제한)이다. 이번 일치 검증(희수·민혁)과는 따로, 이후 연계 대상이다.

## 9. 비교와 PASS가 의미하는 것
- 비교 항목: 관절 각도(1 ms), iq(100 µs), 관절 입력 토크(100 µs), 정착시간(목표의 2 % 이내에 들어와 끝까지 유지, 0.3 rad는 ±0.006 rad / 2 rad는 ±0.04 rad), 추종 RMSE.
- 허용치(잠정): 각도 ≤ 1e-3 rad, iq ≤ 0.01 A, 관절 토크 ≤ 0.015 N·m (= N·Kt·0.01), 정착시간 차 ≤ 0.01 s. 양쪽 다 정착 못 하면 정착시간은 N/A.
- 결과: 최대 각도 차 7.2e-6 rad, iq 차 3.1e-4 A, 관절 토크 차 4.6e-4 N·m. 허용치의 약 1/30(iq, 토크)~1/140(각도) 수준.
- 왜 완전히 같지 않나: MuJoCo는 고정 간격에서 전류를 계산하고 토크를 구간 동안 유지하는 방식이라 약간의 적분 오차가 있고, MATLAB은 가변 스텝으로 더 정확하다. MATLAB 간격을 줄이면 변화가 각도 1.6e-6 rad 이하로 작다 → MATLAB 결과는 수렴, 남는 차이는 MuJoCo의 계산 방식 쪽.
- **PASS의 의미**: 두 환경이 같은 가정 모델을 같게 계산한다. **PASS가 아닌 것**: 실제 모터가 이렇게 움직인다는 증명이 아님 (가정값), MuJoCo가 더 낫다/MATLAB이 더 낫다는 결론이 아님.

## 11. 용어 (한 줄)
- **PMSM**: 영구자석 동기 전동기. **FOC**: 전류를 토크 성분(iq)과 자속 성분(id)으로 나눠 제어하는 방식(벡터 제어).
- **dq 변환**: 회전하는 좌표에서 교류를 직류처럼 다루는 변환 (Clarke → Park).
- **역기전력**: 모터가 돌면서 만드는, 인가 전압을 방해하는 전압 (we·ψ).
- **윈드업 / 안티윈드업**: 출력이 막힌 동안 적분이 쌓이는 현상 / 그것을 막는 되먹임.
- **반사 관성**: 기어 반대편 관성이 관절 쪽에서 N²배로 보이는 것.
- **ZOH(샘플-유지)**: 계산한 값을 다음 계산 시점까지 유지.
- **implicitfast / ode23t**: MuJoCo / MATLAB의 적분 방법 이름.
